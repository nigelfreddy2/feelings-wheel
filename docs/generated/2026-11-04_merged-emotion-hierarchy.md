## 4th ring — feasibility assessment

### What would a 4th ring contain?
The current outer (3rd) ring has 145 specific emotions. Several mid clusters are rich enough to support a further level of nuance — for example:

| 3rd-ring emotion | Possible 4th-ring children |
|---|---|
| Overwhelmed (anxious) | Frozen · Flooded · Paralysed |
| Grief | Bereft · Desolate · In mourning |
| Lonely | Estranged · Marginalised · Invisible |
| Furious | Livid · Seething · Incensed |
| Panicked | Hyperventilating · Dissociated |
| Hopeless | Despairing · Despondent · Nihilistic |

### Verdict — not worth it right now
A 4th ring would:
- Add a 4th SVG band at R=390–510 — pushing the viewBox to 1020px, reducing visibility of core labels
- Create segments so narrow that labels are essentially impossible; only tooltips would carry meaning
- Add 50–100 more emotion words (most clinically niche) to a database already at 199 entries
- Complicate the wheel math and hit-test layer significantly

**Better approach for depth:** The DBT dimensions system already provides exactly this level of nuance. When a user selects an emotion, the coaching drawer shows prompting events, body sensations, opposite actions, and coping strategies. This is far more clinically useful than a 4th ring segment.

**Revisit when:** The app has real session data showing users consistently land on certain 3rd-ring emotions and want to distinguish further. That data should drive 4th-ring additions, not upfront speculation.
