# 2026-11-04_20h29 — Zoom-into-sector feature

**User:** nigelfreddy

## Request
Some outer-ring slices still don't show labels. Implement a zoom function.

## Design decision
SVG viewBox crop zoom — native SVG approach, no DOM scaling distortion.
When a core sector is clicked, the viewBox animates to crop into that sector,
magnifying the mid and spec rings to ~2.6x. Labels that were suppressed due to
narrow arcs become clearly readable at zoom.

## Behaviour
- **Click a core**: viewBox animates into that sector (380ms ease-in-out)
- **"← All emotions" button**: appears top-left when zoomed, returns to full wheel
- **Click same core again**: zooms back out AND opens intensity overlay for that emotion
- **Click mid/spec while zoomed**: opens intensity overlay as normal
- **Tooltip**: still works at any zoom level

## Animation
CSS `transition` cannot interpolate SVG viewBox (it's a string). Instead:
- Four viewBox numbers stored as state `[x, y, w, h]`
- `useEffect` fires on `selectedCoreKey` change, starts a `requestAnimationFrame` loop
- Lerps from current vb values to target over 380ms with ease-in-out curve
- `vbRef` tracks current values between frames without causing re-renders mid-animation

## computeZoomViewBox
- Target radius: mid-ring centre + 80 = R≈285
- Blend: 55% toward sector centroid from wheel centre
- ViewBox size: 800 / 2.6 ≈ 307px of SVG space — fills the sector comfortably
